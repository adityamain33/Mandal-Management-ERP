# MandalSetu ERP (मंडळ सेतू) 🚩

**MandalSetu** is an ERP and festival management system designed specifically for Sarvajanik Ganeshotsav and Navratri Mandals, trust committees, and socio-cultural organizations.

It features complete support for:
- 🧾 **Donation & Receipt Generation**: Instant 80G compliant Marathi/English PDF receipts with QR codes and WhatsApp/SMS sharing.
- 💰 **Double-Entry Accounting**: Real-time cashbook, general ledger, income vs expense tracking, and festival budget auditing.
- 👥 **Member & Volunteer Coordination**: Duty rosters, tasks, attendance, and blood group directory.
- 🎪 **Vendor & Expense Management**: Vendor quotations, advance tracking, and maker-checker approval workflows.
- 📅 **Festival & Event Scheduler**: Daily aarti schedules, prasad distribution, immersion processions, and cultural programs.


### 1. Backend Setup

```bash
cd backend
npm install
npm run seed     # Seeds demo users, festival, accounts & transactions
npm run dev      # Starts API on http://localhost:5000
```

### 2. Frontend Setup

Open a separate terminal:
```bash
cd frontend
npm install
npm run dev      # Starts UI on http://localhost:5173
```

Visit **`http://localhost:5173`** in your browser.
